# Composition archetypes

Almost everything we make is one of eight shapes. An archetype is a proven arrangement of attention: where the eye lands first, where it goes next, and where it leaves. Pick the archetype that matches the job, then dress it with the chosen direction's ingredients. The same archetype works on a phone, a billboard, a stream overlay and an email.

| Archetype | The job | Reading order | Natural signature moves | Lives in | How it fails |
|---|---|---|---|---|---|
| **1. Stage** | Make one thing unmissable: a date, a prize, a name, a launch | Caption → hero → action | Caption over hero number; white speaks | Campaign heroes, key art, launch posts, page headers, app welcome | A second hero creeps in; the action floats mid-frame |
| **2. Face-off** | Turn two sides into an event | Context → side A → side B → state on the axis | Versus lockup; cue light on the state (LIVE) | Fixtures, match cards, thumbnails, trailers, match rooms | Unequal crests or type sizes that imply a favourite |
| **3. Scoreboard** | Let people compare many things quickly and trust them | Title → top row → scan → highlighted row | Scoreboard grid; cue line on one row | Standings, schedules, results, line-ups, tables, recap emails | Zebra stripes, boxes round every cell, colour on every number |
| **4. Path** | Show a journey and where someone is on it | Start → lit route → destination | Cue line along the route; hairlines for the rest | Brackets, road-to-final, onboarding, wizards, progress | Every branch lit; no clear destination |
| **5. Spotlight** | Give a person the stage | Face → lower-third → context | Lower-third; one light source; cut edge | MVPs, player features, host intros, testimonials, profiles | Type over the face; stock people; several light colours |
| **6. Fork** | Help someone choose a path with confidence | Question → options → consequences → choose | Cut edge; at most one badge; white action | Sign-up paths, plans, ticket types, formats, setup choices | More than three options; badges everywhere; hidden trade-offs |
| **7. Verdict** | Record an outcome with dignity | Caption → winner → score → the other side | Caption over hero; resolved versus lockup; cue underline | Results, trophy screens, champion posts, confirmations | Red for the loser; confetti; gloating copy |
| **8. Pulse** | Keep people current while something is live | Live marker → newest → history | Cue light as live dot; mono timestamps; grid | Match centre, live feeds, overlays, venue screens, activity | Everything animating; newest at the bottom; no sense of time |

## Carrying an archetype across formats

Recompose; never shrink. Each format keeps the reading order but changes what fits.

- **16:9** (key art, streams, venue screens): the full archetype plus one supporting element. Largest type.
- **4:5** (feed): the full archetype, stacked. Hero in the top half, action in the bottom quarter.
- **9:16** (stories, vertical video): hero and action only; the rest moves to a second frame or is cut. Keep the top and bottom 12% clear of platform chrome.
- **In product:** the archetype becomes a view - stage = page header, scoreboard = table, pulse = feed, path = stepper, fork = choice cards, verdict = confirmation.
- **Single line** (push, subject line, SMS): the archetype's hero as words. Stage → "Karachi Valorant Open starts at 8:00 PM". Verdict → "Night Owls win the final, 3–1".

## Combining archetypes

A long page is a sequence of archetypes, one per band, each band with one job: a stage, then a scoreboard, then a spotlight, then a fork. Two archetypes fighting in one band is the most common cause of a cluttered page.

## Archetype × direction

The archetype is the shape of attention; the direction is the world it lives in. The same verdict is a quiet confirmation row in Command Console, a full-bleed champion card in Trophy, and a printed results sheet in Daylight. Choose both, deliberately.
