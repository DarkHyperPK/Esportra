# Composition archetypes

Almost everything we make is one of eight shapes. An archetype is a proven arrangement of attention: where the eye lands first, where it goes next, where it leaves. Choose the archetype for the **job**, and the direction for the **moment**. The same archetype works on a phone, a billboard, a stream overlay and an email.

---

## 1. Stage
**Job:** make one thing unmissable - a date, a prize, a name, an idea.
**Reading order:** caption → hero → (supporting line) → action.
```
CAPTION · CONTEXT
HERO (huge)
supporting line
                              [ ACTION ]
```
**Rules:** one hero at 3-10× everything else; caption anchored top-left; action released bottom-right; dark rest opposite the hero.
**Lives in:** campaign heroes, key art, announcements, page headers, welcome screens, venue "next match".
**Failure → fix:** a second hero creeps in (prize and date both huge) → demote one to a facts band. The action floats mid-frame → release it to the bottom-right.

## 2. Face-off
**Job:** turn two sides into an event.
**Reading order:** context → side A → side B → state on the axis.
```
          GRAND FINAL · BO5
 [crest]                    [crest]
 Night Owls      VS     Crimson Five
            ● LIVE · MAP 3
```
**Rules:** perfect symmetry on a centre axis (equal crest size, equal type size) until the result; the state (live, time, score) sits on the axis in the cue colour.
**Lives in:** fixtures, match cards, thumbnails, match rooms, trailers, push previews.
**Failure → fix:** unequal crests or names imply a favourite → equalise. Winner and loser styled before the result → keep neutral until resolved.

## 3. Scoreboard
**Job:** let people compare many things quickly and trust them.
**Reading order:** title → top row → scan → the highlighted row.
```
GROUP A · STANDINGS
┌──┬───────────────┬─────┬─────┐
│01│ Night Owls    │ 5–0 │ +38 │
│02│▌Lahore Lynx   │ 4–1 │ +21 │  ← the viewer's team: 2 px cue
└──┴───────────────┴─────┴─────┘
```
**Rules:** gap-px grid; tabular numbers right-aligned; one row carries the cue; order is the story.
**Lives in:** standings, schedules, results, line-ups, admin tables, recap emails, summary strips.
**Failure → fix:** zebra stripes, boxes around every cell, colour on every number → hairline grid, white numbers, colour only for state.

## 4. Path
**Job:** show a journey and where someone is on it.
**Reading order:** start → lit route → destination.
**Rules:** the route to the destination (or the current step) carries the cue line; everything else is hairline; the destination is visually heavier.
**Lives in:** brackets, road-to-final, onboarding, wizards, progress trackers, roadmaps.
**Failure → fix:** every branch lit → light only the viewer's route. No clear destination → make the final/goal the heaviest node.

## 5. Spotlight
**Job:** give a person the stage.
**Reading order:** face → lower-third → context.
**Rules:** one light source; dark space for type beside (not over) the face; the lower-third (rose tick, role caption, name) at bottom-left.
**Lives in:** MVPs, player features, host intros, testimonials, profiles, creator partnerships.
**Failure → fix:** type over the face → move to the dark side. Stock-looking people → real community photos with consent.

## 6. Fork
**Job:** help someone choose a path with confidence.
**Reading order:** question → options → consequences → choose.
**Rules:** two or three options, equal visual weight; each with what happens next; at most one badge ("Fastest", "Recommended"); clicking is the action (no footer).
**Lives in:** sign-up paths, setup choices, plans, ticket types, formats.
**Failure → fix:** more than three options → group or progressive disclosure. Trade-offs hidden → state the consequence on each card.

## 7. Verdict
**Job:** record an outcome with dignity.
**Reading order:** caption → winner → score → the other side.
**Rules:** stillness; the winner's name as hero; resolved versus lockup (winner white, other side grey); cue underline under the winner; the runners-up named.
**Lives in:** results, trophy screens, champion posts, confirmations ("You're checked in"), payment receipts.
**Failure → fix:** red for the loser, confetti, gloating copy → grey, one reveal, respect.

## 8. Pulse
**Job:** keep people current while something is live.
**Reading order:** live marker → newest → history.
**Rules:** newest on top; one live marker (the cue); mono timestamps; only the live values change.
**Lives in:** match centres, live feeds, activity logs, stream overlays, venue screens, "Needs you" queues.
**Failure → fix:** everything animating → only the new item arrives. Newest at the bottom → reverse.

## Carrying an archetype across formats

Recompose; never shrink.
- **16:9:** full archetype + one supporting element.
- **4:5:** full archetype stacked; hero top half; action bottom quarter.
- **9:16:** hero and action only; keep the top and bottom 12% clear of platform UI.
- **In product:** stage = page header, scoreboard = table, pulse = feed, path = stepper, fork = choice cards, verdict = confirmation state.
- **Single line (push, subject, SMS):** the hero as words.

## Combining archetypes

A long page is a sequence of archetypes, one per band, each with one job. Two archetypes in one band is the most common cause of clutter.

## Archetype × direction

The archetype is the shape of attention; the direction is the world it lives in. A verdict is a quiet confirmation row in Command Console, a full-bleed champion card in Trophy, a printed results sheet in Daylight. Choose both, deliberately.
