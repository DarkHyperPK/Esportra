# Direction dossier: Daylight

> The stage with the lights up. Bone paper, black ink, greys for context, one cue in rose.

Daylight is for surfaces that are printed, read in bright places, or carry money and rules where trust means *paper-like* clarity: payout statements, receipts, invoices, rulebooks, printed brackets on a venue wall, emails, sponsor one-pagers, parent guides. Everything else in the recipe still holds; only the ground inverts.

---

## 1. Signal profile

| Signal | Fits when | Doesn't fit when |
|---|---|---|
| S1 Surface | Print, PDFs, receipts, invoices, payout statements, emails, rulebooks, daylight venue signage | Live match rooms |
| S2 Mode | Read, Operate around money/rules | Persuade-heavy campaigns |
| S3 Arc | Outcome (payouts), nerves (rules before play), trouble | Live match |
| S4 Audience | Anyone needing a record: captains, organizers, partners, parents, accountants | - |
| S5 Density | Handful to a table | - |
| S6 Emotion | Trust, reassurance, certainty | Hype |
| S7 Latitude | L0-L1 | - |

## 2. Ingredients

### Ground and ink
| Role | Value |
|---|---|
| Paper | #FAFAF9 (screens) / uncoated white (print) |
| Ink | #09090B |
| Secondary ink | #52525B |
| Hint ink | #71717A |
| Hairline | #E4E4E7 |
| Cue | Rose #E11D48 (one step darker than on dark ground for contrast on paper) |
| Signals | Emerald #047857, amber #B45309, red #B91C1C (darker variants for AA on paper) |

### Type
Same families; heavier weight contrast so it survives print and glare. Body Inter 400 at 11-12 pt print / 15-16 px screen. Numbers Poppins 800 tabular. Captions mono 8-9 pt print.

### Structure
Tables in ink with hairlines (the scoreboard grid on paper). Every monetary line: amount, currency, date, time zone, reference. Headers state what the document is and for whom. Footers carry the legal line and a way to get help.

### Imagery
Minimal. Crests and partner marks in monochrome where allowed.

### Motion
None (email-safe only).

### Voice
Pure referee. Exact, dated, no celebration on financial documents.

## 3. Do / don't

| Do | Don't |
|---|---|
| "PKR 50,000 paid to Night Owls on 18 Nov 2026, 14:20 PKT. Ref ESP-PAY-8841." | "Your winnings are on the way!" |
| Darker signal colours on paper | The dark-ground tones reused on white (fail contrast) |
| One cue (status or total) | Rose headings |

---

## 4. Worked example: payout statement (PDF)

Header: `ESPORTRA · PAYOUT STATEMENT` + tournament name + recipient. Hero: the total paid, large. Scoreboard table: placement, team, amount, method, date/time PKT, reference. Status pill "Paid" in dark emerald. Footer: how to raise a query, legal entity line.
