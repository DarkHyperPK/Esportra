# Archived Migrations

This folder contains legacy migration scripts and one-off database fixes that were used during development.

## Active Migrations

Active Supabase migrations are located in `supabase/migrations/` and follow the naming convention:
- `YYYYMMDD_description.sql`

These are the migrations that Supabase automatically applies when deploying.

## Archive Contents

The files in this archive folder are:
- Legacy migration scripts from early development
- One-off database fixes and patches
- Comprehensive system implementation scripts
- Test and diagnostic scripts

These files are kept for reference but are not actively used in the migration system.
