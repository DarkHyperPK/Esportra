PART 5 — HOW IT ALL CONNECTS (END-TO-END FLOW)
================================================================================

FACEIT OAuth flow:
    User clicks "Link FACEIT"
    -> useFaceitAccount opens accounts.faceit.com
       with redirect_uri=https://esportra.com/functions/v1/faceit-oauth
    -> FACEIT redirects browser to esportra.com/functions/v1/faceit-oauth?code=xxx
    -> FaceitOAuthCallback.tsx (React route) relays to
       /settings?faceit_callback=true&code=xxx
    -> Settings.tsx calls POST backend.esportra.com/api/integrations/faceit/callback
    -> .NET backend exchanges code+PKCE with FACEIT, saves to DB ✅

Riot OAuth flow:
    User clicks "Link Riot"
    -> useRiotAccount opens auth.riotgames.com
       with redirect_uri=https://esportra.com/auth/riot/callback
    -> Riot redirects browser to esportra.com/auth/riot/callback?code=xxx
    -> RiotOAuthCallback.tsx (React route) relays to
       /settings?riot_callback=true&code=xxx
    -> Settings.tsx calls POST backend.esportra.com/api/integrations/riot/callback
    -> .NET backend exchanges code with Riot, saves to DB ✅

All other API calls (tournaments, teams, bracket, veto, etc.):
    apiClient.ts -> https://backend.esportra.com/api/...

All SignalR real-time:
    signalrClient.ts -> wss://backend.esportra.com/hubs/...
    JWT passed as ?access_token= query string (WebSocket handshake can't set headers)

Supabase (api.esportra.com) — used for:
    Auth only: login, signup, password reset, Discord OAuth
    Storage only: file/image uploads and downloads
    Edge Functions: NONE (all decommissioned — see Part 6)

================================================================================
PART 7 — ROLLBACK
================================================================================

.NET backend:
    Coolify -> your .NET app -> Deployments tab -> click previous build -> Rollback

Frontend:
    Revert the commit that broke it, push to main
    OR: Coolify -> Frontend app -> Deployments -> Rollback

Redis failure:
    Non-critical — Redis is only cache + rate limiting
    App falls back gracefully. Redis restart self-heals.

================================================================================
PART 8 — TROUBLESHOOTING
================================================================================

SYMPTOM                              FIX
-------                              ---
curl /health returns 502             Container crashed. Check Coolify logs.
                                     Usually wrong Postgres port (5432 vs 5433)
                                     or wrong Redis password.

SignalR 401 Unauthorized             Supabase__JwtSecret mismatch.
                                     Must match exactly what Supabase shows
                                     in Studio -> Settings -> API -> JWT Settings.

CORS error in browser                Wrong ASPNETCORE_ENVIRONMENT env var.
                                     Check appsettings.{Env}.json has your
                                     frontend domain in AllowedOrigins.

Frontend still calling edge funcs    Build vars not marked as "Build Variable"
                                     in Coolify. Enable the toggle, force redeploy.

FACEIT OAuth 404 on callback         FACEIT developer dashboard is missing the
                                     redirect URI. Add:
                                     https://esportra.com/functions/v1/faceit-oauth

Riot OAuth 400 on callback           Riot developer dashboard is missing:
                                     https://esportra.com/auth/riot/callback

500 errors on any API endpoint       Check Coolify container logs.
                                     ConnectionStrings__Postgres is most common cause.

Redis connection refused             Use container hostname (not localhost).
                                     Redis is on internal Docker network.

Coolify not auto-deploying           Webhook may point to old IP.
                                     Coolify -> Sources -> GitHub App -> re-auth.
