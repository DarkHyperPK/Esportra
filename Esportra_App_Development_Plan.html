Executive Summary

Esportra is a fully-built web platform. The entire backend (Supabase + custom .NET API + SignalR hubs), all business logic, and all screens are already running in production. The app is built in React + TypeScript + Vite.

This plan uses Capacitor to wrap that existing React web app into a native iOS and Android shell — meaning roughly 70% of the work is already done. The effort is focused on mobile UI polish, native plugins (push notifications, camera, deep links), and App Store preparation — not rebuilding from scratch.

02

What is Capacitor? (For the Owner)

This is the most important concept in the whole plan. Here is a simple explanation:

The Web App (Already Built)

The Esportra website — all the screens, logic, and data — runs in a browser. It's built in React and TypeScript. Every feature already works here today.

Capacitor (The Bridge)

Capacitor is a tool that takes the existing web app and wraps it inside a native iOS or Android shell — like putting a website inside a purpose-built mobile container.

The Native App (What We Ship)

The result is a real app on the App Store and Google Play. It installs like any other app. Users never see a browser — it looks and feels native.

How Capacitor Accesses Native Phone Features

The web app alone cannot access the phone's camera, push notifications, or GPS. Capacitor solves this with official plugins that bridge JavaScript to native iOS/Android APIs:

Native FeatureCapacitor PluginUsed For
Push Notifications@capacitor/push-notificationsMatch alerts, check-in reminders, team invites
Camera & Photo Library@capacitor/cameraAvatar photo, match evidence screenshot upload
Network Detection@capacitor/networkShow offline banner, pause real-time connections
Deep Links / URL Handling@capacitor/appOpen tournament/venue/veto links directly in app
Native Share Sheet@capacitor/shareShare tournament or venue link with friends
Haptic Feedback@capacitor/hapticsVibrate on match result, booking confirmation
Splash Screen@capacitor/splash-screenBlack branded splash on app open (already configured)
Status Bar@capacitor/status-barDark status bar to match app theme (already configured)
Bottom Line for the Owner

Capacitor means the development team writes code once (in React, the same language as the website) and it runs on both iPhone and Android. The app gets all native phone features through plugins. It's the smartest, fastest, and most cost-effective path for this project.

Phase 1
Foundation & Native Shell
First build running on a real phone
3 Weeks
Weeks 1 – 3

Tasks

  • Run npx cap add ios and npx cap add android
  • Configure app icon and splash screen assets
  • Set iOS Bundle ID and Android package name
  • Build bottom tab navigation component for mobile
  • Detect Capacitor environment (Capacitor.isNativePlatform())
  • Show bottom nav only when running in app (not on web)
  • Audit and fix all touch targets (>44px)
  • Fix horizontal scroll on small screens (<390px)
  • Test OAuth redirects on iOS + Android
  • Configure Supabase OAuth callbacks for mobile scheme
  • Set up environment variables for mobile builds
  • Integrate Sentry for mobile crash reporting

Deliverables

  • TestFlight (iOS) + APK (Android) build that installs and boots
  • Login / sign-up working end-to-end on device
  • Bottom tab navigation visible and functional on mobile
Exit Criteria

A tester can install the app, log in with Google, and browse tournaments — all on a real device with no console errors.

Risks & Mitigations

High
App Store Review Rejection
Mitigation: Review Apple & Google guidelines in Phase 1. Ensure Privacy Policy, OAuth flows, and data declarations comply before submission. Budget 1 week for re-submission.
High
iOS APNs Push Notification Setup
Mitigation: Configure APNs certificates in Phase 2 Week 1. Test on real iPhone immediately — never rely on simulator for push. Use Firebase Cloud Messaging as a unified layer.
Medium
OAuth Redirect on Mobile
Mitigation: Configure Supabase redirect URLs for com.esportra.app:// custom scheme. Test Google + Discord OAuth on real devices in Phase 1 before building further.
Medium
SignalR Performance on Mobile Networks
Mitigation: Implement reconnect on app foreground. Add polling fallback if WebSocket drops. Test on throttled 3G network in Phase 3.
Low
Capacitor Plugin Version Conflicts
Mitigation: Pin all Capacitor plugins to the same major version (v7). Test each plugin immediately after installation on both platforms.
