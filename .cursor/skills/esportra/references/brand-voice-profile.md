# Esportra Voice Profile

Operational voice profile for site copy, CTAs, feature descriptions, and marketing.  
Derived from live product copy in `HeroSection`, landing components, and `PlatformPromise`.

## Identity

- **Product**: Esportra — esports tournament management + venue booking
- **Audience**: Players, organizers, venue owners (Pakistan-first grassroots esports, global ambition)
- **Tone**: Aspirational but grounded. Competitive. Premium dark aesthetic. Not bro-marketing, not corporate SaaS filler.

## Rhythm

- Short punchy headlines; longer supporting lines only when they earn their place
- Prefer contrast pairs: problem/opportunity, promise/proof, local/global
- Uppercase tracking on section labels (`FOR THE UNSEEN LEGENDS`, `OUR COMMITMENT`)
- CTAs are action verbs with personality (`Jack In`, not `Get Started`)

## Vocabulary

**Use:**
- competition, arena, ecosystem, integrity, verified, legacy, main stage, ladder, roster, prize pool
- concrete player journeys (sign up → team → tournament → check-in → results)
- trust signals (transparency, foul play, permanent records)

**Avoid:**
- "revolutionary", "game-changer", "cutting-edge", "synergy", "leverage"
- generic SaaS ("streamline your workflow", "all-in-one platform")
- fake urgency ("limited time", "don't miss out")
- LinkedIn thought-leader cadence

## CTA patterns

| Context | Label style |
|---------|-------------|
| Player signup | `Jack In` |
| Browse events | `Browse Tournaments` |
| Organizer | `Host Tournament` |
| Secondary | Ghost/outline buttons, trophy icon where relevant |

## Copy structure for landing sections

1. Eyebrow label (uppercase, tracked, muted accent)
2. Headline (large, light or black weight, optional rose accent span)
3. One supporting sentence max before CTA
4. Feature cards: title (medium) + one proof-oriented sentence (light, white/40)

## Hard bans

- Fake curiosity hooks
- "Excited to announce"
- Unearned superlatives without proof
- Invented metrics, player counts, or sponsor names
- Emoji in product copy (matches coding guidelines)

## When extending copy

1. Read existing strings in the target component first
2. Match sentence length and weight to neighboring copy
3. Keep one idea per headline
4. Run `brand-voice` skill checks against this profile
5. For social repurposing, hand off to `content-engine` + `crosspost` — do not paste landing copy verbatim to X/LinkedIn
