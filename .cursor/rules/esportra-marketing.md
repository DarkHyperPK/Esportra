# Esportra Marketing Copy

Applies when editing public-facing copy, headlines, CTAs, or landing narrative.

## Before editing

1. Read `.cursor/skills/esportra/references/brand-voice-profile.md`
2. Read `.cursor/skills/esportra/references/marketing-copy-locations.md`
3. Activate `brand-voice` skill

## Voice (summary)

- Aspirational, competitive, premium dark — not bro-marketing or SaaS filler
- Contrast headlines ("Talent is universal. Opportunity is not.")
- Action CTAs with personality (`Jack In`, `Host Tournament`)
- One idea per headline; proof over adjectives
- Rose accent (`rose-500`) for key emphasis spans only

## Skills by deliverable

| Deliverable | Skills |
|-------------|--------|
| Hero / section headline | `brand-voice`, `product-lens` |
| Feature tab copy | `brand-voice` |
| About / story page | `article-writing`, `brand-voice` |
| Sponsor taglines (admin) | `brand-voice` — keep short, proof-oriented |
| Promo video script | `content-engine`, `remotion-video-creation` |
| Social posts from launch | `content-engine` → `crosspost` (separate from site copy) |

## Not website ad copy

These skills serve **other channels** — do not paste their output directly onto the landing page:

- `investor-outreach` / `investor-materials` — fundraising emails and decks
- `lead-intelligence` — B2B prospect outreach
- `crosspost` / `x-api` — social platforms
- `openclaw-persona-forge` — unrelated OpenClaw agent personas
- `market-research` — positioning research input, not final copy

## UI pairing

Match copy changes to `UI_STYLE_GUIDE.md` and `web-design-quality` rule. Headlines use `font-heading`; body uses light weight at `text-white/40` for supporting text.
